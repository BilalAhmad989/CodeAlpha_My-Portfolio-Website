# CodeAlpha_My-Portfolio-Website
# Bilal Ahmad | Front-End Developer Portfolio

A responsive, single-page personal portfolio built with plain **HTML, CSS and JavaScript**. It was created as **Task 3** of my Front-End Development internship at **CodeAlpha**.

🔗 **Live site:** https://bilalahmad989.github.io/portfolio/

## About the project

The portfolio presents my background as a BS Information Technology student at the University of Swat, along with my internships, teaching experience, volunteering, scholarships and certificates.

## Sections

- **About:** short introduction and skills
- **Education:** BS IT, HSSC and SSC
- **Internships:** CodeAlpha and Elevate Labs
- **Teaching:** Qurtaba Public School & College, Sabawoon Public School & College
- **Volunteering:** Alkhidmat Foundation Swat, LASOONA
- **Scholarships:** Dalda Foundation Trust, Rehmatul Lil Alameen
- **Certificates:** ASPIRE, Dalda, Bano Qabil
- **Extracurricular Activities:** appreciation certificate, graphic designing, entrepreneurship
- **Contact:** email, phone and GitHub

## Features

- Fully responsive layout for desktop, tablet and mobile
- Automatic light and dark theme based on the device setting
- Sticky navbar with active-section highlight, scroll progress bar and mobile menu
- Smooth scrolling and fade-in animations as sections appear
- Hover effects on cards, buttons, links and skill chips
- Click-to-enlarge image viewer with next/previous arrows and keyboard support (Esc, ← →)
- Back-to-top button
- Respects reduced-motion settings for accessibility

## Built with

- HTML5
- CSS3 (Grid, Flexbox, custom properties, media queries)
- JavaScript (vanilla, no libraries)

1. Download or clone the repository:
   ```bash
   git clone https://github.com/BilalAhmad989/portfolio.git
   ```
2. Open `index.html` in any web browser. No installation or build step is needed.
